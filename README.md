# ghci_mobile

Progressive Web App (PWA) e ambiente simulado para o GHCi de Haskell no celular.
Construído com Vanilla CSS, HTML e Node.js para integração e execução segura do ambiente REPL.

## Funcionalidades
- Interface Mobile responsiva (Premium Dark Mode)
- Execução segura e isolada de comandos GHCi (Timeout de 15s)
- Opção de carregar arquivos `.hs` locais para a área de código
- Menu de comandos úteis integrado
- Installável offline como App Nativo (PWA)
